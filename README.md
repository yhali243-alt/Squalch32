# DISCO VALLEY · SqueFM  (VST3)

Psychedelic FM / ladder / comb synth with a 32-step LFO sequencer — for Zenon, prog, psytech, dark and hi-tech.

**Install / update on Mac** — paste in Terminal:
```
curl -sL https://raw.githubusercontent.com/yhali243-alt/Squalch32/main/build_mac.sh | bash
```
Then restart Cubase. Plugin: Instruments → **Disco Valley → SqueFM**.

## Pages
- **SYNTH** – Osc A/B (morph, sync, phase reset), FM operator (ratio or fixed Hz for sub-audio ripping, index, feedback, target), mixer, zap pitch-env, ladder 6–24 dB LP/BP/HP, comb (keytracked, ± feedback), filter/amp/mod envelopes.
- **SEQUENCER** – 32 steps; every step has an OPEN (top) and CLOSED (bottom) cutoff level, its own shape and its own speed in BPM divisions or free Hz.
- **MOD** – 3 LFOs (BPM/Hz), Spit generator, Chaos, 8-slot matrix with "via" scaling; negative amount = invert.
- **FX** – Talk (formants), Bite + Crush, Phaser, Delay, Reverb, quick genre guide.
- Footer – 4 Macros (map in the matrix), master, live scope.
