# DISCO VALLEY · SqueFM (VST3)

Psychedelic synth for Zenon, psytech, dark prog, organic psy and hi-tech:
saw/morph oscillators + clean sine sub, **4-operator FM voice** (8 algorithms, 10 sound families),
resonant ZDF ladder with **dedicated Filter LFO -> cutoff** (WOW), post-filter growl,
32-step sequencer where every step is its own LFO, plus FM / character / resonance / drive /
probability / accent lanes.

**Install / update on Mac** – paste in Terminal:

```
curl -sL https://raw.githubusercontent.com/yhali243-alt/Squalch32/main/build_mac.sh | bash
```

Then restart Cubase. Plugin: Instruments → **Disco Valley → SqueFM**.
The previous build is kept as `~/Squalch32-build/SqueFM.previous.vst3`.

Pages: MAIN (body, FM character, WOW/filter, bite, filter LFO, movement, space) · FM (voice, algorithm,
4 operators) · SYNTH · SEQUENCER (+ lanes) · MOD (LFOs, matrix) · FX.

Reference patches: `A Fat WOW`, `B Aggressive Swamp`, `C HiTech FM Creature`, `D Psy FM Lead`.
Dev notes: `.claude/skills/squefm-sound-design/SKILL.md`.
